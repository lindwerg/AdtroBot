# Astraro Bot Visual Style Guide

## Ресерч

### Тренды в астро-ботах:
1. **Космический/мистический стиль** - тёмный фон, звёзды, градиенты
2. **Единая цветовая палитра** - глубокий синий/фиолетовый + золотые акценты
3. **Минималистичные иллюстрации** - не перегруженные деталями
4. **Типографика** - элегантные шрифты с засечками для заголовков

### Референсы стиля:
- Co-Star App: минимализм, чёрно-белый + акценты
- The Pattern: градиенты, космические текстуры
- Sanctuary: мягкие пастельные тона, иллюстрации

## Единый стиль Astraro

### Цветовая палитра:
- **Primary**: Deep purple/indigo (#2E1065 → #4C1D95)
- **Secondary**: Cosmic gold (#F59E0B)
- **Background**: Dark starfield (#0F0A1E)
- **Accent**: Soft violet (#8B5CF6)

### Стилевой промпт для FLUX:

```
Style: Mystical cosmic illustration, dark indigo background with soft golden accents,
ethereal glowing elements, minimalist design, subtle star particles,
soft gradients from deep purple to cosmic blue, elegant and professional,
modern astrology aesthetic, high quality digital art
```

### Нужные изображения:

1. **welcome.png** - Приветствие/главное меню
   - Элементы: созвездия, мягкое свечение, приветственная атмосфера
   
2. **horoscope.png** - Гороскоп
   - Элементы: знак зодиака (универсальный), солнце, звёзды
   
3. **tarot_menu.png** - Меню Таро
   - Элементы: карты таро, мистическое свечение
   
4. **profile.png** - Профиль
   - Элементы: силуэт человека, звёзды, персонализация
   
5. **subscription.png** - Подписка/Premium
   - Элементы: корона/звезда, золотые акценты, премиальность
   
6. **natal.png** - Натальная карта
   - Элементы: круговая диаграмма, планеты, астрологические символы

### Формат:
- Размер: 800x400 (горизонтальный для Telegram)
- Формат: PNG
- Без текста на изображениях (текст в сообщении бота)
